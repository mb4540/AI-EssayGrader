Global Preconditions (before running any tests)

  • Application is deployed and accessible (local dev or production URL)
  • At least one test account exists (or use the Register tests first)
  • Browser is Chrome, Firefox, Safari, or Edge (latest version)
  • JavaScript is enabled
  • Network connectivity is available (for API calls)
  • Test with a clean browser session (clear localStorage before starting)

How to Use This Test Suite

  1. Start with Authentication tests to ensure you can log in.
  2. Then run Student Bridge tests to set up student data.
  3. Run Assignment tests to create assignments.
  4. Run Submission & Grading tests with real essay content.
  5. Use the checkboxes and status buttons on each page to track progress.
  6. Add notes in the text areas for any issues found.
  7. Results are stored in your browser's localStorage (per page).
